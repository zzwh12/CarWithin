# 英文界面接入方案

2026-11-24 用户确认后实施。

- 界面支持简体中文、英文，跟随 iOS 为 App 选择的首选语言；其他语言回退中文。
- 接入现有翻译稿，保留动态参数、协议数据与现有功能。开发阶段版本和构建号不变。
- 更新清单保留 `schemaVersion: 1` 与中文 `notes`，新增可选 `notesEn`。旧版忽略新字段；新版英文界面优先英文，缺失或空白回退中文。
- GitHub Release 正文保持中文。历史记录和“完整发布说明”直接显示原始 Markdown，不为逐条历史记录额外下载 JSON。
- 生成脚本增加可选 `--notes-en` 文件参数。下载验证、更新发现、构建号比较规则保持现有实现。
- 接入后验证编译、语言回退、动态参数和新旧更新清单兼容；真机仪表与英文布局未验证时明确注明。

## 接入实现

- 运行时资源位于 `App/Localization`，语言查找和单次参数展开由 `Sources/TDSCarKitCore/Localization.swift` 提供。完整 Swift 句子保持为翻译键，编号参数保留原始插值顺序。
- 英文网页使用 `Tools/prepare_english_receiver.py` 从中文播放器和翻译表生成 `Receiver.en.html`。播放器变动后重新运行生成脚本；发现残留中文会报错。服务端按 App 语言选择页面，并将页面缓存版本包含语言标识，避免复用另一语言的旧页面。
- 权限提示通过中英文 `InfoPlist.strings` 提供。证书安装页沿用同一套语言资源。
- `Tools/generate_project.py` 包含字符串目录、隐私提示与英文播放器资源，重新生成项目不会丢失它们。
- `Tools/LocalizationSmoke.swift` 覆盖真实 Bundle 中的中英文选择、不支持语言回退、动态参数不被二次展开，以及网页语言和版本替换。`Tools/UpdateSmoke.swift` 增加英文说明和空白回退覆盖。
- 当前仍需真机检查英文布局、仪表投屏、语音和锁屏行为。翻译和编译校验不能替代这些运行验证。
