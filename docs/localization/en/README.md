# CarWithin 英文本地化翻译准备稿

准备日期：2026-11-24。基于本地开发工作区，包括当时尚未公开的 Wi-Fi 密码和仪表说明修改。此目录仅用于后续接入；尚未修改 App 的语言行为、工程资源或版本号，也未合并外部 PR。

## 文件与覆盖范围

| 文件 | 用途 |
| --- | --- |
| `translations.tsv` | 便于查看的完整中英对照表；包含 ID、范围、源码位置、参数表达式和备注 |
| `translations.json` | 同一份内容的结构化版本；后续接入与校验以此为依据 |
| `Localizable.xcstrings` | 741 条原生静态文案的中英字符串目录，尚未加入应用 Target |
| `InfoPlist.strings` | 4 条英文权限说明；后续放入应用资源的 `en.lproj` |
| `source-snapshot.json` | 原文所在文件的 SHA-256，方便接入前检查源码是否变化 |

共 1,036 条记录：原生代码中的 936 条去重文案、22 条插值分支片段、66 条网页播放器文案、8 条证书安装页文案、4 条权限说明。包含主界面、设置、使用说明、更新与下载、关于与支持、无障碍提示、各类输出连接状态、错误提示和诊断日志。

记录数量不等于界面控件数量：重复使用的相同原文合并记录；部分记录是动态模板或句子片段；网页与原生相同的原文仍按各自接入范围单独列出。仅有英文、数字、协议名称的现有字符串不需中译英，未重复收录。中文代码注释、开发工具输出、README、在线 GitHub Release 正文以及系统提供的错误文本不属于此翻译包。

## 阅读和参数约定

- `native`：原生 UI、业务错误和诊断；`native-fragment`：插值内的条件分支；`browser`：JavaScript/HTML 播放器；`certificate-page`：HTTPS 安装页；`permission`：系统权限说明。
- `literal` 为静态原文；`template` 中 `{1}`、`{2}` 等按源码插值出现顺序对应参数。它们是翻译资料占位符，**不是可直接用于运行时的 iOS 格式参数**。237 条模板留在对照表中，未混入静态字符串目录。
- JSON 的 `sources[].arguments` 保留原始 Swift 参数表达式；同一句的不同调用位置分别保留。网页模板按页面原文的参数顺序排列，需在 JavaScript 接入时对应实际表达式；源码行号用于定位，不表示该字符串已接入。
- TSV 中 `\n` 表示换行，JSON 中保留实际换行。动态参数应在接入时转换为带明确类型的 Swift 本地化插值或位置格式参数，不能用简单字符串替换猜测类型。
- `%d`、`%.1f`、`0x%04X`、`%%` 等现有格式说明符原样保留。不要把普通百分号或协议载荷改成翻译参数。
- `S200` 这类末尾接日期的文字、`E` 开头的片段以及网页错误前缀，应尽可能重构成完整句子的本地化模板。不要依赖中文词序拼出英文。

## 后续接入要点

1. 将字符串目录加入应用 Target 的资源，声明支持 `zh-Hans` 和 `en`。保留中文回退；通过 iOS 本地化机制遵循系统或用户的 App 首选语言，不需要自行扫描系统语言字符串。
2. UIKit 的 `setTitle`、`UILabel.text`、占位符、菜单、错误描述等改为读取本地化资源。SwiftUI 的 `Text`、`Button` 与动态 `String` 分别检查，不能假定导入目录就全部生效。
3. 将动态模板接入带类型的本地化参数，重构片段拼接。数量文案如观看设备数、日志计数，在接入时按英文单复数使用复数规则或完整的不变表达，不能从本稿推断已有复数配置。
4. 本地化原生错误和日志时，先检查它们是否参与逻辑判断。例如代码存在 `message.contains("已请求")`；应改用结构化状态或其他稳定标识，避免语言改变影响功能。Keychain 标识、协议值和诊断内部标识也不可机械替换。
5. 浏览器页面需独立接入文案表，决定遵循浏览器语言还是 App 语言，并设置正确的 HTML `lang`。证书安装页及服务端发送的状态也要同步；原生 `.xcstrings` 不会自动翻译网页。
6. 将英文权限说明放入 `en.lproj/InfoPlist.strings`，核对 Target 资源包含关系，保留现有中文说明。证书内部名称与配置描述文件显示名称需分别处理。
7. 公开 Release Markdown、下载的更新说明不会因 App 本地化自动变成英文；是否提供双语正文应另行决定。
8. 使用中文和英文分别运行：检查长按钮、设置副标题、弹窗、窄屏/大字体、无障碍朗读、仪表连接、画中画、下载和网页播放器。翻译稿可编译不代表运行时已经验证。
